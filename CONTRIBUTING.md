# Contributing

## Scope

This repository is a portfolio-oriented experimental platform. Prefer small, isolated improvements over broad rewrites.

## Expectations

- Keep changes scoped to a clear subsystem.
- Do not commit secrets, local paths, or generated credentials.
- Update docs when you change public behavior, setup, or project structure.
- Call out external dependencies or provider assumptions in pull requests.

## Good contribution targets

- documentation clarity
- developer setup improvements
- safer tool execution behavior
- better frontend/backend naming consistency
- tests around stable non-demo paths

## Avoid without prior coordination

- package-wide renames
- model provider lock-in changes
- major architecture rewrites
- destructive cleanup of experimental modules
